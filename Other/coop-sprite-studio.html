Unique item/block behavior

To give this tool or block unique behavior, enter a key such as magicSword, then define items.magicSword in the pack-wide JavaScript module. Add hooks such as onUse, onHit, onBlockUse, onBlockBreak, onBlockPlace, onProjectileHit, or onTick. Blocks can use onBlockUse to respond to a player right-click.

Pack-wide JavaScript module

One module is shared by the whole pack: services are reusable code functions, items holds behavior keyed by the Pack behavior key, and features holds independent game-wide hooks. Built-in game.services.rayTrace(maxDistance, maxHits) returns ordered block and player hits and is available to all code, but is not editable.
